# Victor Zion's Portfolio

Welcome to the source code for my personal portfolio website: [zhayon-io](https://zhayon-io.vercel.app). 

This website serves to showcase my projects, skills, and experience as a web developer. It features a modern, responsive design with smooth animations and dark mode support.

## 🚀 Features

- **Project Showcase**: Detailed cards with image previews and technologies used for my past work.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.
- **Dark/Light Mode**: User-selectable theme support.
- **Smooth Animations**: Powered by Framer Motion.

## 🛠️ Technologies Used

- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **shadcn/ui**
- **Framer Motion**

## 🏃‍♂️ Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd zhayon-io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   bun install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   # or
   bun dev
   ```

4. Open your browser and visit the local URL provided in your terminal (typically `http://localhost:5173`).
